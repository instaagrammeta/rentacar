# Ресурсы для сборки десктопа

Поместите сюда иконку приложения для установщика Windows:

- `icon.ico` — иконка приложения (рекомендуется 256×256, формат ICO).

Иконка используется Electron Builder (`desktop/package.json` → `build.win.icon`
и `nsis`). Если файл отсутствует, Electron Builder применит иконку по умолчанию.
